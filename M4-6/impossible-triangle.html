ขั้นที่ 1 · เปลี่ยนแท่งเป็นเวกเตอร์

ให้แต่ละแท่งเป็นลูกศรหนึ่งเส้น

a + b + c = 0 เพราะรูปปิดสนิท เดินตามลูกศรครบทั้งสามเส้น แล้วจะกลับมาที่จุดเริ่มต้น
a·b = b·c = c·a = 0 เนื่องจากทุกมุมเป็นมุมฉาก และเวกเตอร์ที่ตั้งฉากกัน ดอทกันแล้วได้ศูนย์

ห้าบรรทัด หนึ่งข้อขัดแย้ง

a + b + c = 0 เพราะสามเหลี่ยมปิดสนิท
a·b = 0, b·c = 0, c·a = 0 เพราะทุกมุมเป็นมุมฉาก
a·(a + b + c) = a·0 = 0 นำ a ไปดอททั้งสองข้าง
a·a + a·b + a·c = 0 กระจาย
|a|² + 0 + 0 = 0 ⟹ |a| = 0 มุมฉากสองมุมทำให้สองพจน์หลังเป็นศูนย์

แท่ง a ยาวเป็นศูนย์ สามเหลี่ยมนี้จึงไม่มีอยู่จริง

ใช้วิธีเดียวกันกับ b และ c ก็ได้ผลเหมือนกัน ลูกศรสามเส้นที่ตั้งฉากกันทุกคู่ชี้ไปสามทิศทางที่เป็นอิสระต่อกัน จึงบวกกันแล้วเป็นศูนย์ไม่ได้เลย
