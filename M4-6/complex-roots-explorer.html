คู่มือเชิงภาพ § i

จำนวนเชิงซ้อน · บทที่ 1

รากที่คุณมองไม่เห็นบนกราฟธรรมดา

แก้สมการ x2 = −1
จัดรูปใหม่ x2 + 1 = 0

ลองพล็อตกราฟ y = x² + 1 ด้วยจำนวนจริงเพียงอย่างเดียว จะเห็นว่ากราฟไม่ตัดแกน x เลย แต่เมื่อเอียงกราฟเดียวกันนี้เข้าสู่ ระนาบจำนวนเชิงซ้อน จะปรากฏราก 2 ราก ขึ้นตรงจุดที่พื้นผิวแตะระดับน้ำทะเลพอดี

เส้นจำนวนจริง — มุมมองเส้นโค้ง
ลากเพื่อหมุนดูรอบๆ
มุมมอง
ระดับความสูงต่ำสุด 1.00 ที่ x = 0
จำนวนรากที่พบ 0 — กราฟไม่แตะ y = 0 เลย

ตอนนี้ใช้ได้เฉพาะจำนวนจริงเท่านั้น กราฟ y = x² + 1 อยู่เหนือแกน x ทั้งเส้น จึงไม่มีรากให้พบ

01

เส้นจำนวนจริง

พล็อตกราฟ y = x² + 1 โดยใช้จำนวนจริงเท่านั้น กราฟนี้จะไม่มีวันต่ำกว่า 1

02

ไม่ตัดแกน

เพราะค่าต่ำสุดคือ 1 กราฟจึงไม่มีวันแตะแกน x — ไม่มีจำนวนจริง x ใดที่ทำให้ x² + 1 = 0

03

เปิดกราฟออกสู่ระนาบ

ให้ x กลายเป็นจำนวนเชิงซ้อน w = a + bi แล้วพล็อตความสูง |w² + 1| ทั่วทั้งระนาบ ไม่ใช่แค่บนเส้นจำนวน

04

ระดับน้ำทะเล

พื้นผิวลดลงจนแตะศูนย์พอดีที่ 2 จุด คือ w = i และ w = −i นี่คือรากเชิงซ้อนของ x² = −1

สลับไปที่ระนาบเชิงซ้อน แล้วลากภายในกราฟเพื่อหมุนดูรอบๆ — ทุกรากคือจุดที่ |w² + 1| แตะศูนย์พอดี
