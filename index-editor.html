แก้ไขหน้าแรก (index.html)

กำลังโหลด…

เปิด index.html บน GitHub ↗
วิธีนำไปใช้บนเว็บจริง
  1. แก้ไขการ์ดและข้อความในหน้านี้ (ดูผลได้ทันทีในช่องตัวอย่าง) — งานที่แก้จะบันทึกไว้ในเบราว์เซอร์นี้อัตโนมัติ
  2. กด 📋 คัดลอกโค้ด index.html
  3. กด เปิด index.html บน GitHub → ไอคอนดินสอ ✏️ → กด Ctrl+A (มือถือ: เลือกทั้งหมด) แล้ววางทับ
  4. กด Commit changes แล้วรอ 1–2 นาที หน้าเว็บจะอัปเดต
  5. การ์ดใหม่จะยังไม่มีรูปตัวอย่างในตอนแรก บอตของ GitHub จะถ่ายภาพหน้าจอให้อัตโนมัติภายในไม่กี่นาที

    ส่วนหัว และท้ายหน้า
    การ์ด “เร็ว ๆ นี้”
    ชื่อหัวข้อระดับชั้น (เมื่อเปิด “แบ่งหัวข้อตามระดับชั้น”)

    ไฟล์ .html ใน repo ที่ยังไม่มีการ์ดบนหน้าแรก (รวมการ์ดที่ซ่อนไว้ด้วย) กด “เพิ่ม” เพื่อสร้างการ์ดใหม่ไว้บนสุดของรายการ พร้อมป้าย “ใหม่”

    กำลังโหลดรายชื่อไฟล์จาก GitHub…
