# ไฟล์ร่างการ์ด (drafts)

Claude เขียนการ์ดใหม่ไว้ในโฟลเดอร์นี้ ไฟล์ละ 1 ครั้งที่ขอ (เช่น `2026-11-03-sets-basic.js`)
การ์ดในโฟลเดอร์นี้ **ยังไม่แสดงในแอป** จนกว่าจะนำเข้า `flashcards/cards.js`

1. เปิด https://natthaphat-math.github.io/Math-contents/card-editor.html แท็บ "ร่างจาก Claude"
2. ตรวจ แก้ และกด "เพิ่ม" การ์ดที่จะใช้ (หรือ "ไม่ใช้")
3. กด "ส่งออก cards.js" แล้ววางแทนไฟล์ cards.js บน GitHub
4. ไฟล์ร่างที่ตรวจครบแล้วลบทิ้งได้

วิธีเขียนไฟล์ร่าง: ดู `CLAUDE.md` ที่รากของ repo และกฎด้านบนของ `flashcards/cards.js`
