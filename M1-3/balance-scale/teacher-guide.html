คู่มือครู: ตาชั่งสมการ

เครื่องมือนี้ใช้ประกอบบทเรียน “การแก้สมการเชิงเส้นตัวแปรเดียวโดยใช้สมบัติการเท่ากัน” ชั้นมัธยมศึกษาปีที่ 1 นักเรียนใช้บนสมาร์ตโฟนของตนเอง (คนเดียวหรือเป็นคู่) และครูฉายขึ้นจอหน้าชั้นได้

แนวคิดสำคัญที่ต้องการให้นักเรียนค้นพบ

  • สิ่งที่ทำกับข้างหนึ่งของสมการ ต้องทำกับอีกข้างหนึ่งด้วย ตาชั่งจึงจะยังสมดุล (สมบัติการเท่ากัน)
  • แอปยอมให้นักเรียนทำกับข้างเดียวได้ ตาชั่งจะเอียงให้เห็น สมการจะเปลี่ยนเป็นเครื่องหมาย ≠ และมีข้อความเตือนว่าไม่สมดุล แอปจะไม่แก้ให้อัตโนมัติ
  • ถ้าเลือกการกระทำผิด (เช่น เพิ่มก้อนแทนที่จะนำออก หรือคูณแทนที่จะแบ่งกลุ่ม) ตาชั่งยังสมดุล แต่แอปจะถามชวนคิดว่าเข้าใกล้คำตอบหรือไม่

สมการสำเร็จรูป (ปุ่ม “เลือกสมการ”)

ตอนสมการสมบัติที่ใช้
ตอนที่ 1 การบวกและการลบx + 3 = 8 · x + 5 = 12 · x + 2 = 9สมบัติการเท่ากันเกี่ยวกับการลบ (นำก้อนออกทั้งสองข้าง)
ตอนที่ 2 การคูณและการหาร2x = 8 · 3x = 12 · 2x + 1 = 9สมบัติการเท่ากันเกี่ยวกับการหาร (แบ่งกลุ่ม) และการลบ

สมการ 2x + 1 = 9 ถ้านักเรียนพยายาม “แบ่ง 2 กลุ่ม” ก่อน แอปจะไม่ยอมและอธิบายว่าก้อน 1 ก้อนแบ่งให้เท่ากันไม่ได้ เป็นจังหวะดีสำหรับอภิปรายว่าควรทำขั้นใดก่อน

ปุ่มและการควบคุม

ส่วนหน้าที่
① จะทำอะไรกับตาชั่ง− นำก้อนออก / + เพิ่มก้อน (ก้อนหนักก้อนละ 1) · ÷ แบ่งกลุ่ม = แบ่งของบนจานเป็น k กลุ่มเท่า ๆ กันแล้วเก็บไว้ 1 กลุ่ม (หารด้วย k) · × คูณ = เพิ่มของบนจานเป็น k เท่า
จำนวน (− / +)เลือกจำนวนก้อน (1–20) หรือจำนวนกลุ่ม/ตัวคูณ (2–9)
② ทำกับข้างใดข้างซ้ายเท่านั้น / ทั้งสองข้าง / ข้างขวาเท่านั้น — ต้องเลือกใหม่ทุกครั้ง เพื่อให้นักเรียนตัดสินใจเอง
ปุ่มสีน้ำเงินแสดงประโยคของสิ่งที่จะทำ เช่น “นำก้อนออก 3 ก้อน จากทั้งสองข้าง” กดเพื่อทำ
ย้อนกลับ / เริ่มใหม่ยกเลิกขั้นล่าสุด / กลับไปที่สมการเริ่มต้น
ทายผลก่อนทำเมื่อเปิด ก่อนทำกับข้างเดียว นักเรียนต้องทายว่า ข้างซ้ายหนักกว่า / สมดุล / ข้างขวาหนักกว่า แล้วแอปจึงเฉลยผล
ตรวจสอบคำตอบนักเรียนพิมพ์ค่า x ที่หาได้ แอปจะแทนค่าในสมการเริ่มต้น เปลี่ยนกล่อง x เป็นกล่องที่หนักเท่ากับค่านั้น และแสดงว่าสมดุลหรือไม่ (แอปไม่เฉลยค่า x ให้นักเรียน)
บันทึกขั้นตอนซ่อนไว้ก่อน เพราะนักเรียนต้องเขียนสมการแต่ละขั้นลงในใบงานเอง เมื่อเขียนเสร็จให้กด “เทียบกับบันทึกของเครื่อง” แล้วยืนยัน จึงจะเห็นบันทึก เช่น x + 3 − 3 = 8 − 3 → x = 5 พร้อมเหตุผล “นำ 3 มาลบทั้งสองข้างของสมการ”
ปุ่ม กก (มุมขวาบน)ขยายตัวอักษรสำหรับฉายจอ

โหมดครู

เปิดโหมดครูโดยเพิ่ม ?teacher=1 ต่อท้ายที่อยู่เว็บ เช่น https://ชื่อผู้ใช้.github.io/ชื่อrepo/?teacher=1 จะมีป้าย “โหมดครู” และการ์ด “เครื่องมือครู” ซึ่งมี

  • แสดงบันทึกขั้นตอนตลอดเวลา — สำหรับอภิปรายทั้งชั้นบนจอ
  • ทำขั้นถัดไปให้ดู และ แก้สมการให้ดูทั้งหมด — แอปทำทีละขั้นแบบทำทั้งสองข้าง (ใช้ได้เมื่อตาชั่งสมดุล)
  • เปิดเผยค่า x
  • สร้างสมการเอง (ในกล่อง “เลือกสมการ”) รูปแบบ x + a = b, ax = b, ax + b = c ใช้จำนวนเต็มบวก คำตอบเป็นจำนวนเต็มบวก สัมประสิทธิ์ของ x ไม่เกิน 8 และตัวเลขไม่เกิน 40 (x อยู่ข้างขวาก็ได้ เช่น 12 = 3x) จากนั้นคัดลอก ลิงก์สำหรับนักเรียน ไปแชร์ได้ (ลิงก์นี้ไม่เปิดโหมดครู)

หมายเหตุ: โหมดครูเป็นเพียงการซ่อนเครื่องมือจากหน้าจอปกติ ไม่ใช่ระบบรหัสผ่าน ให้ใช้ลิงก์ปกติ (ไม่มี ?teacher=1) กับนักเรียน

ตัวเลือกในที่อยู่เว็บ (ใช้ร่วมกันได้ด้วย &)

ตัวเลือกผล
?teacher=1เปิดโหมดครู
?log=1แสดงบันทึกขั้นตอนตั้งแต่เริ่ม (สำหรับฉายจอ)
?eq=2x%2B1%3D9 หรือ ?eq=2x+1=9เปิดสมการที่กำหนด
?predict=1เปิด “ทายผลก่อนทำ” ไว้ตั้งแต่เริ่ม
?big=1ตัวอักษรขนาดใหญ่สำหรับฉายจอ

ตัวอย่างสำหรับฉายจอ: ?teacher=1&log=1&big=1

ลำดับการสอนที่แนะนำ

  1. ฉายสมการ x + 3 = 8 ให้นักเรียนสังเกตว่าตาชั่งสมดุล และสมการตรงกับของบนจาน
  2. ให้นักเรียนเปิด “ทายผลก่อนทำ” แล้วลองนำก้อนออกจากข้างซ้ายเท่านั้น ทาย → ดูผล → อภิปรายว่าทำไมไม่สมดุล
  3. ให้นักเรียนหาวิธีทำให้เหลือ x ตามลำพังโดยตาชั่งยังสมดุล และเขียนสมการทุกขั้นลงใบงาน
  4. ตรวจสอบคำตอบด้วยการแทนค่า แล้วกด “เทียบกับบันทึกของเครื่อง”
  5. ตอนที่ 2 ทำแบบเดียวกันกับ 2x = 8, 3x = 12 และ 2x + 1 = 9

ความเป็นส่วนตัวและการใช้งานออฟไลน์

  • ไม่มีการเข้าสู่ระบบ ไม่เก็บหรือส่งข้อมูลนักเรียน ไม่มีระบบวิเคราะห์การใช้งาน
  • เมื่อเปิดจากเว็บไซต์ครั้งแรกแล้ว แอปจะเก็บไฟล์ไว้ในเครื่อง ใช้ต่อได้แม้สัญญาณหลุด
  • เมื่อรีเฟรชหน้า แอปจะกลับไปเริ่มต้นใหม่ (ไม่มีการบันทึกความคืบหน้าในเครื่อง)
